Weekend build

Building a Gapless, Local AI Voice Assistant

I’ve always wanted a truly local, private AI voice assistant. Not a cloud service listening to my room, but a real Jarvis-style sidecar running completely offline on my own hardware.

This weekend, while watching the F1 race, I decided to finally build one on my Fedora machine. My setup is an HP laptop with a Ryzen 5 processor, which means the CPU is good but not infinite. Running a massive LLM and a real-time TTS engine together needs serious optimization, or the audio stutters and the AI starts reading code like it’s stuck in the Matrix.

Architecture

Two models talking to each other

To make this work, I used two separate AI models that communicate seamlessly.

  • The Brain: Ministral, which handles logic and conversation.
  • The Voice: Kokoro-82M, a tiny but very realistic TTS model.

The real magic happens in a custom Python bridge script. It listens to the LLM, cleans the text, and feeds it to the voice engine in real time.

Note: in the scripts below, replace YOUR_USERNAME with your actual Linux username.

Step 1

System dependencies

Before touching any AI, the operating system needs the audio routing and Python tools. The key package here is espeak-ng, which Kokoro uses under the hood. 

# Update your package list
sudo dnf update -y

# Install espeak-ng, Python, and wget
sudo dnf install espeak-ng python3 python3-pip wget -y

If you are on Ubuntu or Debian, simply replace dnf with apt.

Step 2

Setting up the brain

There are two ways to get the LLM onto the machine. Ollama is the easy route, while manual Hugging Face downloads give you more control.

Method A: Ollama route

# Install Ollama
curl -fsSL https://ollama.com/install.sh | sh

# Download the Ministral model
ollama pull ministral

Method B: Manual Hugging Face route

# Create a folder for your manual models
mkdir -p ~/AI/models
cd ~/AI/models

# Download a specific GGUF model directly from Hugging Face
wget https://huggingface.co/path/to/your/chosen/ministral-8b.Q4_K_M.gguf

# Create a Modelfile pointing to your downloaded file
echo 'FROM ./ministral-8b.Q4_K_M.gguf' > Modelfile

# Tell Ollama to build a local runner from your file
ollama create my-custom-ministral -f Modelfile

The biggest trap was CPU bottlenecks. LLMs are greedy and can grab every core available, which leaves the voice engine starving. The fix was to create a custom profile that caps the thread usage and leaves room for audio.

The CPU cap profile

cd ~
echo 'FROM ministral' > Modelfile
# Note: Change '6' to exactly half of your total CPU threads
echo 'PARAMETER num_thread 6' >> Modelfile

# Build the capped profile
ollama create ministral-fast -f Modelfile
rm Modelfile

Step 5

The bridge script

This is the secret sauce. Piping Ollama’s output straight into TTS sounds awful, so the bridge strips terminal junk, translates emojis, and keeps playback smooth.

Show the Python bridge Expand

Python bridge

import os, sys, time, re, threading, queue
import numpy as np
import sounddevice as sd
import emoji

# --- SYSTEM PATCHES ---
orig_load = np.load
def patched_load(*args, **kwargs):
    kwargs['allow_pickle'] = True
    return orig_load(*args, **kwargs)
np.load = patched_load
os.environ["PHONEMIZER_ESPEAK_LIBRARY"] = "/usr/lib64/libespeak-ng.so.1"
from kokoro_onnx import Kokoro

# --- PATHS (CHANGE 'YOUR_USERNAME'!) ---
BASE_DIR = "/home/YOUR_USERNAME/AI/voice/kokoro"
MODEL_PATH = os.path.join(BASE_DIR, "kokoro-v0_19.onnx")
VOICE_PATH = os.path.join(BASE_DIR, "heart_voice.npy")
LOG_PATH = "/tmp/heart_session.log"

# Init Engine
kokoro = Kokoro(MODEL_PATH, VOICE_PATH)
heart_data = np.load(VOICE_PATH)
kokoro.voices = {"af_heart": heart_data}

# --- THE GAPLESS PIPELINE ---
text_queue = queue.Queue()
audio_queue = queue.Queue()

def tts_worker():
    while True:
        text = text_queue.get()
        if text is None: break
        
        # Emoji Translation & Deep Clean
        clean = emoji.demojize(text).replace('_', ' ').replace(':', '') 
        clean = re.sub(r'[*#>-]', '', clean) 
        clean = re.sub(r'[^a-zA-Z0-9\s\.\,\!\?\'\"\-]', ' ', clean) 
        clean = re.sub(r'\s+', ' ', clean).strip() 
        
        if len(clean) > 1:
            try:
                samples, rate = kokoro.create(clean, voice="af_heart", speed=1.1, lang="en-us")
                
                # Silence Trimmer (Cuts dead air from the generated audio)
                threshold = 0.005
                mask = np.abs(samples) > threshold
                if np.any(mask):
                    first = max(0, np.argmax(mask) - int(rate * 0.05))
                    last = min(len(samples), len(mask) - np.argmax(mask[::-1]) + int(rate * 0.05))
                    samples = samples[first:last]
                
                audio_queue.put((samples, rate))
            except: pass
        text_queue.task_done()

def playback_worker():
    # Persistent Audio Stream (No handshake lag!)
    stream = sd.OutputStream(samplerate=24000, channels=1, blocksize=2048, latency='high')
    stream.start()
    
    while True:
        item = audio_queue.get()
        if item is None: break
        samples, rate = item
        audio_data = np.expand_dims(samples, axis=1).astype(np.float32)
        stream.write(audio_data)
        audio_queue.task_done()

threading.Thread(target=tts_worker, daemon=True).start()
threading.Thread(target=playback_worker, daemon=True).start()

# --- THE READER ---
if not os.path.exists(LOG_PATH): open(LOG_PATH, 'w').close()
raw_buffer, muted_line = "", False

with open(LOG_PATH, "r", encoding='utf-8', errors='ignore') as f:
    f.seek(0, 0)
    while True:
        chunk = f.read(10)
        if not chunk:
            time.sleep(0.05)
            continue
        
        raw_buffer += chunk
        
        # Resolve hidden backspaces from LLM typos
        while '\x08' in raw_buffer or '\b' in raw_buffer:
            raw_buffer = re.sub(r'[^\x08\b][\x08\b]', '', raw_buffer)
            raw_buffer = re.sub(r'^[\x08\b]+', '', raw_buffer)

        # Protect ANSI Codes & Strip Braille Spinners
        if '\x1B' in raw_buffer:
            clean_buf = re.sub(r'\x1B\[[0-?]*[ -/]*[@-~]', '', raw_buffer)
            if '\x1B' in clean_buf:
                if len(raw_buffer) - raw_buffer.rfind('\x1B') < 30: continue 
                else: raw_buffer = clean_buf.replace('\x1B', '')
            else: raw_buffer = clean_buf
        raw_buffer = re.sub(r'[\u2800-\u28FF]', '', raw_buffer).replace('\r', '')
        
        # Mute Lock (Ignores user typing)
        if muted_line:
            if '\n' in raw_buffer: muted_line, raw_buffer = False, raw_buffer.split('\n', 1)[-1]
            else: raw_buffer = ""
            continue
            
        # Prompt Detector
        if any(p in raw_buffer.lower() for p in [">>>", "send a message", "script started"]):
            muted_line, raw_buffer = True, ""
            continue
            
        # Sentence Chunking
        while True:
            match = re.search(r'([.!?]+\s|\n)', raw_buffer)
            if match:
                text_queue.put(raw_buffer[:match.end()])
                raw_buffer = raw_buffer[match.end():]
            elif len(raw_buffer) > 400:
                last_space = raw_buffer.rfind(' ')
                if last_space > 0:
                    text_queue.put(raw_buffer[:last_space])
                    raw_buffer = raw_buffer[last_space:]
                else:
                    text_queue.put(raw_buffer)
                    raw_buffer = ""
            else: break

The bridge uses a 3-stage threading pipeline: the reader, the brain, and the mouth. It strips terminal junk, translates emoji into spoken words, keeps the audio stream open, and avoids the annoying lag between sentences.

Step 6

The terminal shortcut

To connect everything together, I used the Linux script command to capture Ollama output and write it to a log file that the bridge watches.

Shell function

voice-ai() {
    # 1. Clean up old sessions to prevent port collisions
    pkill -f ministral_bridge.py
    rm -f /tmp/heart_session.log
    touch /tmp/heart_session.log
    
    # 2. Start the Python bridge in the background (Unbuffered)
    /home/YOUR_USERNAME/AI/voice/kokoro/venv/bin/python3 -u /home/YOUR_USERNAME/AI/voice/kokoro/ministral_bridge.py > /dev/null 2>&1 &
    BRIDGE_PID=$!
    
    echo "Waking up the voice engine..."
    sleep 3 
    
    # 3. Launch the CPU-Capped AI natively
    script -f -q -c "ollama run ministral-fast" /tmp/heart_session.log
    
    # 4. Cleanup on exit
    echo "Shutting down system..."
    kill $BRIDGE_PID
    rm -f /tmp/heart_session.log
}

Reload shell

source ~/.bashrc

Result

What the finished workflow feels like

When everything is wired together, you open a terminal, type voice-ai, ask a question, and the assistant answers completely offline. The whole chain stays local, the audio stays smooth, and the response comes back without the awkward gaps.

Building it was a lot of bash errors, regex nightmares, and threading logic, but the result is worth it. It is the kind of weekend project that feels equal parts ridiculous and perfect.
